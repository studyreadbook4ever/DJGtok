# Changelog

## 0.1.0 — 2026-09-30

Initial public library snapshot as DJGtok (대중교통 토큰화).

* Exact directed canonical-ID-and-mode corridor matching with deterministic ranking and source-evidence ranges.
* Immutable multi-resolution geographic tokenizer with portable JSON persistence and configuration fingerprints.
* Validated journey interchange, independent slices and synthetic reversals.
* Local GTFS adapter and optional Seoul workbook adapter.
* Lightweight core installation, invented examples, command-line interface and platform CI.
* Optional, explicitly experimental contrastive Transformer and dense retrieval code, with failed historical results disclosed.
* MIT license for project-authored work, research attribution and separate external-data provenance; no feeds or pretrained weights bundled.
